# Идеи после сдачи

Этот список сохраняет идеи, чтобы они не прерывали текущую работу. Пункты здесь не входят в MVP и не являются обещанием их реализовать.

## Правило выбора

После сдачи раз в неделю выделять 30 минут на просмотр списка. Выбирать одно улучшение, объяснять его пользу и проверять результат на прежних примерах. Переносить идею в PLAN.md только при явном решении включить её в работу.

## Возможные улучшения

- Подключить ИИ внутри приложения, чтобы получать предварительный разбор без ручного переноса брифа. Потребуются настройка доступа, учёт расходов и обработка ошибок.
- Добавить скилл подготовки предложения клиенту по итогам разбора.
- Добавить скилл подготовки встречи и фиксации договорённостей.
- Добавить план сопровождения внедрения улучшений.
- Добавить шаблоны для других процессов после проверки первого сценария.
- Добавить сохранение черновика анкеты между сеансами.
- Добавить экспорт в другие форматы при появлении реальной потребности.
- Добавить хранение нескольких проектов клиентов с продуманными правилами доступа и работы с данными.
- При необходимости перенести задачи в GitHub Projects. До сдачи достаточно PLAN.md.
